# Alex — What NOT to Save

| Don't save | Why |
|-------------|-----|
| Raw conversation transcript | Privacy risk; no coaching value |
| "Why" the user was kicked out | Irrelevant to forward plan; could be used judgmentally |
| Exact shelter location | Safety risk if data leaks |
| Names of family members or friends | Privacy; no coaching value |
| Emotional state beyond the current session | Stale data leads to wrong assumptions |
| Credit card numbers or SSN | Never — Alex should never ask for these |

## Session Re-engagement Prompt

"Welcome back. Last time you had completed 3 of 8 stabilization tasks and chosen the gig income lane. You'd saved $120 toward a security deposit. Want to pick up where you left off, or is something new going on?"

— uses Life Map data to personalize the re-engagement without re-asking.
